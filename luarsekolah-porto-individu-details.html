User Registration & Data Management System

💻 Demo Information

Environment
Localhost (XAMPP/Laragon)

View Website

User Registration & Data Management System merupakan aplikasi website berbasis PHP Native yang dikembangkan sebagai tugas akhir individu pada program Web Developer Luarsekolah. Website ini dirancang untuk mengimplementasikan sistem autentikasi pengguna serta pengelolaan data menggunakan fitur Create, Read, Update, Delete (CRUD) yang terintegrasi dengan database MySQL.

Project ini memiliki dua jenis hak akses, yaitu Admin dan User. User dapat melakukan registrasi akun dan login ke dalam sistem, sedangkan Admin memiliki hak akses penuh untuk mengelola data melalui fitur CRUD. Seluruh proses pengembangan, mulai dari perancangan database, implementasi sistem registrasi, login, logout, hingga pengelolaan data dilakukan secara mandiri sebagai implementasi pembelajaran pengembangan aplikasi web menggunakan PHP Native, HTML, CSS, Bootstrap, JavaScript, dan MySQL.
